ExileWorth is the new name for Vaaluation. The app keeps its red icon, dark
interface, controls, and settings. The GitHub repository and website now use
the ExileWorth name.

- macOS: extract the signed and notarized ZIP, quit Vaaluation, and replace the
  old app with ExileWorth.app. If prompted, grant ExileWorth Accessibility
  permission for in-game price checks.
- Windows 11 x64 preview: quit Vaaluation, extract the entire ZIP, and launch
  ExileWorth.exe. The portable Windows build is unsigned.
