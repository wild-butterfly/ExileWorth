Install ExileWorth on Windows

Set up the portable Path of Exile 1 price checker on Windows 11 x64.

Download and run the preview

Download the ExileWorth Windows ZIP. Extract the entire archive and run ExileWorth.exe from the extracted folder. The preview includes its runtime. It is unsigned, so Microsoft Defender SmartScreen may show a warning.

Check an item price

  1. Open the English Path of Exile 1 client in Windowed or Windowed Fullscreen mode.
  2. Hover an item and press Ctrl + Alt + D. Select Covens if you play Covens of Umbra.
  3. Choose modifier filters, then select Apply filters to refine the asking prices shown.

If the shortcut is unavailable, copy an item in the game and select Check clipboard. Run the game and ExileWorth at the same privilege level. Closing the window hides it to the system tray.

Currency rates, incoming trade requests, and trade history are currently macOS features.
